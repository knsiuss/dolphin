# Pod Memory

Kept by the memory keeper (skill: dolphin-memory).

- `shared.md` — decisions with provenance, conventions, project
  state. Budget: ≤150 lines, hard.
- `<tag>.md` — one file per session: open work and local lessons so a
  session can wake up mid-thought. Budget: ≤100 lines each, hard.

Rules: correct, don't contradict. Every decision carries its reason
and date. No secrets, credentials, or personal data — ever.
